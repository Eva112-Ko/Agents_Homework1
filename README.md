# Agents_Homework1

Вариант А

Мини-трекер учебных задач, сделанный с ИИ двумя способами

- tracker-v1.html — прямое задание (чат 1)
- tracker-v2.html — сначала спецификация, потом реализация (чат 2)
- spec/ (разбита на 4 файла при загрузке) — спецификация в формате OpenSpec, без CLI: proposal.md, spec.md, design.md, tasks.md
- prompts.txt — тексты всех запросов
- notes.md — отчёт, таблица проверок T1–T5 и еще кое-что
- v1-start.png, v2-start.png — скриншоты

Модель: Claude Opus 5.5  

Запуск
Скачать tracker-v1.html или tracker-v2.html и открыть в браузере. Установка не нужна, интернет не нужен
